fix(ai): support missing sheet parameters and implement activate_sheet command

- `useChat.ts`: Fixed a major bug where the AI's `sheet` parameter for modifying commands (write_range, write_formula, format_range, create_chart, clear_range) was being completely ignored by the execution engine. This caused dashboards to overwrite the active sheet instead of targeting the intended sheet.
- `useChat.ts`: Implemented the `activate_sheet` command in the execution switch. The system prompt tells the AI it can use this, but it wasn't implemented, causing "Unknown action" errors.
- `useChat.ts`: Added regex extraction to pull out only the JSON object from the `<EXCEL_CMD>` block. This prevents "Unexpected non-whitespace character after JSON" errors when the AI accidentally leaves explanatory text inside the tags.
- `ExcelService.ts`: Updated `formatRange` to support the `sheetName` parameter consistently.
