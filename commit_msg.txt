fix(ui): prevent chat from freezing by hiding raw command outputs from the UI

- `useChat.ts`: When the AI retrieved large datasets using commands like `get_sheet_data`, the raw JSON array (which could be tens of thousands of characters long) was being directly appended to the user-facing chat bubble's markdown text. This caused the React Markdown parser to freeze the browser's main thread while attempting to render it, resulting in a completely broken/blank UI experience.
- `types.ts` & `useChat.ts`: The raw data outputs are now safely stored in a dedicated `commandOutputs` field on the `ChatMessage` object, completely hidden from the UI renderer. They are dynamically appended to the context payload only when sending the history to the LLM, ensuring the AI still gets the data without crashing the user's browser.
